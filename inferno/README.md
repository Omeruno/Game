# Отступник

Мрачный 3D-платформер в духе INSIDE: тёмные силуэты, туман, свечение бездны, никакого интерфейса, кроме самого необходимого. Управление рассчитано на телефон.

**Запуск:** открой `inferno/index.html` в браузере. Подойдёт и GitHub Pages. Three.js грузится с CDN, а если CDN недоступен — из `js/lib/three.min.js`.

## Сюжет

Бесёнок триста лет сторожил врата Лимба. Фея пообещала ему свободу в обмен на ключ от врат, и он отдал ключ. Теперь он предатель, и на него охотится весь Ад.

Сначала фея идёт рядом и светит в темноте. В конце пещер Лимба её уносит Ловчий, крылатый демон, куда-то вниз. Бесёнок спускается по кругам, чтобы её найти. В конце каждого круга его ждёт страж.

Главный поворот: девятый круг (Коцит) — это круг **предателей**. Герой спускается туда, где ему самое место.

## Управление

| Действие | Телефон | Клавиатура |
|---|---|---|
| Идти | стик слева (появляется под пальцем) | ← → / A D |
| Прыжок | кнопка ▲ | Пробел / ↑ / W |
| Пригнуться, спрятаться | стик вниз | ↓ / S |
| Схватить ящик, дёрнуть рычаг | кнопка ✋ (зажать) | E / Shift |
| Пауза | ❚❚ | Esc |

Уступы бесёнок берёт сам: подпрыгни у стены, и он подтянется. Если рядом есть за что схватиться, кнопка ✋ подсвечивается.

## Устройство кода

```
inferno/
  index.html         разметка экранов и сенсорных кнопок
  css/style.css      интерфейс поверх 3D
  js/util.js         математика, процедурные текстуры, сохранения
  js/audio.js        процедурный звук на WebAudio (без файлов)
  js/input.js        клавиатура + стик + кнопки
  js/models.js       все модели из примитивов (бесёнок, фея, демоны, босс)
  js/world.js        геометрия уровня, физика, фон, частицы, свет
  js/entities.js     герой, фея, ящики, рычаги, охотники, пёс, босс
  js/game.js         цикл, камера, сценарии, меню, чекпоинты
  js/levels/circle1.js   Круг I: геометрия, триггеры, кат-сцены
```

### Как добавить круг

1. Создай `js/levels/circle2.js` по образцу `circle1.js`: `CIRCLES[2] = function (game) { ... return L; }`.
2. Опиши `theme` (цвета тумана, неба, земли), `checkpoints`, `build()` (блоки `w.solid`, лава `w.lava`, укрытия `w.hide`), `reset(cp)` и `triggers`.
3. Подключи файл в `index.html` после `circle1.js`.
4. В `circle1.js` поле `next` уже указывает на круг 2. Когда он появится, сохранение после Привратника откроет его само.

Кат-сцены пишутся генераторами: `yield 1.5` ждёт полторы секунды, `yield* game.tween(2, k => ...)` плавно анимирует.
